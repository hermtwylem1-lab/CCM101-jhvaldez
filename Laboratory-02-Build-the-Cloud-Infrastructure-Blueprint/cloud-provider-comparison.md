# Cloud Provider Comparison

## Checkpoint 4 – Research the Major Cloud Providers

Cloud computing providers offer many similar infrastructure services, but they use different names and provide different features. The three major public cloud providers researched in this activity are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Cloud Infrastructure Service Comparison

| Infrastructure Component                 | Amazon Web Services (AWS) | Microsoft Azure                   | Google Cloud Platform (GCP) |
| ---------------------------------------- | ------------------------- | --------------------------------- | --------------------------- |
| **Compute**                              | Amazon EC2                | Azure Virtual Machines            | Google Compute Engine       |
| **Storage**                              | Amazon S3                 | Azure Blob Storage                | Google Cloud Storage        |
| **Networking**                           | Amazon VPC                | Azure Virtual Network (VNet)      | Google Cloud VPC            |
| **Identity and Access Management (IAM)** | AWS IAM                   | Microsoft Entra ID and Azure RBAC | Google Cloud IAM            |

AWS uses Amazon EC2 for virtual computing, Amazon S3 for storage, Amazon VPC for virtual networking, and AWS IAM for controlling access to resources.

Azure provides Azure Virtual Machines for compute, Azure Blob Storage for storage, Azure Virtual Network for networking, and Microsoft Entra ID with Azure RBAC for identity and access management.

Google Cloud provides Compute Engine for virtual machines, Cloud Storage for data storage, VPC for networking, and Google Cloud IAM for managing roles and permissions.

## Guide Questions

### 1. Which cloud provider offers the broadest range of services? Explain your answer.

**Amazon Web Services (AWS)** is widely recognized for having one of the broadest selections of cloud services. It provides services for computing, storage, networking, databases, security, analytics, AI, and many other cloud workloads.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend **Microsoft Azure** because it works closely with Microsoft products and technologies. It also provides Microsoft Entra ID and Azure services that can integrate well with existing Microsoft environments.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

**Google Cloud** is widely recognized for its strong AI and machine learning capabilities and its Kubernetes services. Google also developed Kubernetes, which is closely associated with Google Cloud's container and Kubernetes offerings.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent services for **compute, storage, networking, and identity and access management**. Although the service names are different, their main purpose is similar: providing scalable computing resources, storing data, connecting cloud resources, and controlling user access.
