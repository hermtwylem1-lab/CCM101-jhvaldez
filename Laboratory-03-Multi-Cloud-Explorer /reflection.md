
## Mission 3: Become a Multi-Cloud Explorer

This laboratory activity improved my understanding of cloud computing and the differences between major cloud providers. I learned that choosing a cloud platform is not simply about selecting the most popular provider.

The decision should be based on the actual requirements of an organization. AWS can be a strong general-purpose choice, Azure is useful for Microsoft-based environments, and Google Cloud is suitable for AI, machine learning, data, and Kubernetes workloads.

I also learned how cloud services can support or replace traditional servers. The Linux investigation showed me how basic server information can be collected using simple commands such as `lscpu`, `free -h`, and `df -h`.

Overall, this activity helped me understand the role of a cloud solutions architect. Instead of choosing a cloud provider based only on popularity, I learned to consider the technical and business requirements of the client.
