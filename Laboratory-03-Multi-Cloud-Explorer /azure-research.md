## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, databases, networking, security, artificial intelligence, analytics, and application development.

Azure is commonly used by organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID.

## Global Infrastructure

Azure provides cloud infrastructure in many geographic regions around the world.

Azure regions contain data centers where cloud resources can be deployed. Azure also provides Availability Zones in supported regions to help improve the availability and reliability of applications.

Organizations can choose Azure regions based on user location, performance, data requirements, and service availability.

## Cloud Management Console

The Azure Portal is a web-based management interface for Microsoft Azure.

Users can use the portal to create and manage:

- Virtual machines
- Storage accounts
- Databases
- Virtual networks
- Security settings
- Kubernetes clusters
- Monitoring resources

Azure resources can also be managed using Azure CLI, PowerShell, and APIs.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides virtual servers that can run Windows or Linux operating systems.

They can be used for websites, applications, development environments, and enterprise systems.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data.

It can store documents, images, videos, backups, logs, and application files.

### 3. Azure Virtual Network

Azure Virtual Network provides networking for Azure resources.

It allows organizations to create networks, subnets, routing rules, and security settings.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service.

It can manage users, authentication, applications, and access to cloud resources.

## Three Advantages

### 1. Microsoft Integration

Azure provides strong integration with Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft Entra ID.

### 2. Enterprise Support

Azure provides many services designed for businesses and large organizations.

### 3. Hybrid Cloud

Azure supports hybrid cloud environments where organizations can connect their existing on-premises systems with cloud services.

- Virtual desktops
