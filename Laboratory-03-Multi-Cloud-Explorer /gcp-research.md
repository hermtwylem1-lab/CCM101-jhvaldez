# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google.

It provides services for computing, storage, databases, networking, artificial intelligence, machine learning, data analytics, Kubernetes, and application development.

Google Cloud is especially known for its technologies related to artificial intelligence, machine learning, data analytics, and Kubernetes.

## Global Infrastructure

Google Cloud provides cloud infrastructure in many locations around the world.

Its infrastructure is organized into Regions and Zones. A Region is a geographic area, while Zones are locations within a region where cloud resources can be deployed.

Google Cloud provides infrastructure across different areas including North America, South America, Europe, Asia, the Middle East, and Australia.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources.

Users can manage:

- Virtual machines
- Storage
- Databases
- Networks
- Kubernetes clusters
- Artificial intelligence services
- Security and identity
- Monitoring resources

Google Cloud resources can also be managed using the Google Cloud CLI.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can run different operating systems, including Linux and Windows.

It can be used to host websites, applications, development environments, and enterprise workloads.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store files and other unstructured data.

It can be used for backups, media files, datasets, and application data.

### 3. Google Cloud VPC

Google Cloud Virtual Private Cloud (VPC) provides networking for cloud resources.

It allows organizations to configure networks, subnets, firewall rules, and routing.

### 4. Google Kubernetes Engine

Google Kubernetes Engine (GKE) is Google's managed Kubernetes service.

GKE can be used to deploy, manage, and scale containerized applications.

## Three Advantages

### 1. Artificial Intelligence and Machine Learning

Google Cloud provides many services and infrastructure options for artificial intelligence and machine learning.

### 2. Kubernetes

Google is closely associated with Kubernetes, and Google Kubernetes Engine provides a managed Kubernetes environment.

### 3. Data Analytics

Google Cloud provides services that can be used to process and analyze large amounts of data.
