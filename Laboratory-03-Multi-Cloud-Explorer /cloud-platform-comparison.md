## 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. It provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

## 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works well with Windows Server, Microsoft 365, Microsoft Entra ID, and other Microsoft enterprise products.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for artificial intelligence, machine learning, and Kubernetes workloads. It provides AI and machine learning services as well as Google Kubernetes Engine for managing containerized applications.

## 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a wide range of services and can support different types of applications. It can be used for small projects and can also support large enterprise systems as an organization grows.

# Checkpoint 5 – Match the Cloud Services

| Service Category | AWS | Azure | GCP |
|---|---|---|---|
| Virtual Machine | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Object Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Identity Management | AWS IAM | Microsoft Entra ID | Cloud IAM |
| SQL Database | Amazon RDS | Azure SQL Database | Cloud SQL |
| Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Virtual Machine

Virtual machine services provide virtual computing resources that can run operating systems and applications.

- AWS: Amazon EC2
- Azure: Azure Virtual Machines
- GCP: Compute Engine

## Object Storage

Object storage services are used to store files and other unstructured data.

- AWS: Amazon S3
- Azure: Azure Blob Storage
- GCP: Cloud Storage

## Identity Management

Identity management services are used to manage users, authentication, roles, and permissions.

- AWS: AWS IAM
- Azure: Microsoft Entra ID
- GCP: Cloud IAM

## SQL Database

Managed SQL database services provide relational database systems that are managed by the cloud provider.

- AWS: Amazon RDS
- Azure: Azure SQL Database
- GCP: Cloud SQL

## Kubernetes

Managed Kubernetes services are used to deploy and manage containerized applications.

- AWS: Amazon EKS
- Azure: Azure Kubernetes Service
- GCP: Google Kubernetes Engine
