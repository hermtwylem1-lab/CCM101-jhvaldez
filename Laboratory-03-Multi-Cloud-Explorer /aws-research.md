## Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It provides many services for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

AWS can be used by startups, enterprises, government organizations, educational institutions, and individual developers.

## Global Infrastructure

AWS has a global cloud infrastructure made up of geographic Regions and Availability Zones.

A Region is a separate geographic area where AWS provides cloud services. Availability Zones are isolated locations within an AWS Region. Using multiple Availability Zones can help organizations build applications with higher availability.

AWS allows organizations to select locations based on factors such as performance, user location, and data requirements.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

Users can use the console to create and manage:

- Virtual machines
- Storage
- Databases
- Networks
- Security settings
- Kubernetes clusters
- Monitoring resources

AWS resources can also be managed using the AWS Command Line Interface (CLI) and APIs.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers in the AWS cloud.

EC2 can be used to host websites, applications, APIs, and other workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service.

S3 can store files, images, videos, backups, application data, and other objects.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides a private and isolated network environment for AWS resources.

It can contain subnets, routing tables, security groups, and other networking components.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources.

IAM can be used to manage users, groups, roles, and permissions.

## Three Advantages

### 1. Wide Range of Services

AWS provides a large number of cloud services for computing, storage, networking, databases, security, analytics, and artificial intelligence.

### 2. Global Infrastructure

AWS has infrastructure in many geographic locations around the world. This allows organizations to deploy applications closer to their users.

### 3. Scalability

AWS resources can be increased or decreased depending on the workload. This allows applications to handle changes in demand.
