# Client A – Startup Company

## Recommended Platform: Amazon Web Services (AWS)

AWS is recommended for the startup because it provides many services that can support a mobile application and future growth. The company can begin with smaller resources and increase them as the number of users grows. AWS also provides services for application development, storage, databases, and serverless computing. This flexibility can help the startup manage its resources while preparing for future expansion.

### Possible Services

1. **Amazon EC2** – Used to host application servers.
2. **Amazon S3** – Used to store images, files, and application data.
3. **Amazon RDS** – Used to provide a managed relational database.
4. **AWS Lambda** – Used to run application functions without managing servers.

# Client B – University

## Recommended Platform: Microsoft Azure

Azure is the best choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's identity and enterprise technologies. The university can connect its existing infrastructure to Azure and gradually migrate services to the cloud. This can make the migration easier because the university is already familiar with Microsoft technologies.

### Possible Services

1. **Azure Virtual Machines** – Used to host Windows or Linux servers.
2. **Microsoft Entra ID** – Used to manage identities and access.
3. **Azure Blob Storage** – Used to store documents and files.
4. **Azure Virtual Network** – Used to connect and protect cloud resources.

# Client C – AI Research Company

## Recommended Platform: Google Cloud

Google Cloud is recommended for the AI research company because it provides strong artificial intelligence and machine learning capabilities. Google Cloud also provides computing resources that can support demanding AI workloads. The company can use cloud resources to train and run AI models without purchasing and maintaining all hardware locally. This makes GCP a suitable option for research workloads that require high-performance computing.

### Possible Services

1. **Compute Engine** – Used to run high-performance virtual machines.
2. **Vertex AI** – Used to develop and manage AI and machine learning workloads.
3. **Google Kubernetes Engine (GKE)** – Used to deploy containerized AI applications.
4. **Cloud Storage** – Used to store datasets and model files.

---

# Client D – Global E-Commerce Company

## Recommended Platform: Amazon Web Services (AWS)

AWS is recommended for the global e-commerce company because it provides global infrastructure and services for highly available and scalable applications. The company can deploy its application across multiple Availability Zones to improve availability. AWS also provides load balancing and automatic scaling services that can handle changes in customer traffic. These features are useful for a multinational online shopping platform.

### Possible Services

1. **Amazon EC2** – Used to run web and application servers.
2. **Elastic Load Balancing** – Used to distribute traffic across servers.
3. **Amazon EC2 Auto Scaling** – Used to automatically adjust computing capacity.
4. **Amazon S3** – Used to store product images and files.
5. **Amazon RDS** – Used to manage relational databases.
