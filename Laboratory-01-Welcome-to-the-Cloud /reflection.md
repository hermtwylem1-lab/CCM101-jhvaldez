# Reflection


This laboratory activity helped me understand the basic use of a cloud-based Linux environment. Using KillerCoda, I learned how to access Ubuntu, use the terminal, create and manage a Linux user, and check important system information such as the Linux distribution, kernel version, CPU, memory, and disk space. I also learned how to create folders and Markdown files using Linux commands. At first, some commands were confusing and I made a few typing mistakes, but I learned to check the commands carefully and correct my errors. Overall, this activity improved my confidence in using Linux and introduced me to basic cloud computing practices, file organization, documentation, and GitHub, which I believe will be useful for my future IT activities and projects.
